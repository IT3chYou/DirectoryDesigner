# 📁 File Organizer

Welcome to **File Organizer**! 🎯

This Python script automatically organizes files in a directory according to their file extensions.

The program scans the selected directory and its subdirectories, detects supported file types, and moves them into separate folders.

---

## ✨ Features

- 📂 Scans files inside the selected directory
- 🔍 Searches through subdirectories
- 🗂️ Automatically creates folders based on file extensions
- 📦 Moves supported files into their corresponding folders
- 📝 Supports many different file extensions
- 🛡️ Handles errors during scanning and moving
- 🎨 Uses `Rich` for colored terminal output
- 🔄 Uses recursive directory scanning

---
